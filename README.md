# nomad-marketing

Todo lo de NOMAD que **se publica en redes, se gasta en Meta o se mide en la lista de
espera**. El código de la app vive en `marcgodinezmartinez-gif/NOMAD`; ésa es la frontera,
y está escrita para que no se vuelva a mezclar.

- **El taller**: el lienzo editable con el kit, las plantillas y las piezas —
  <https://claude.ai/code/artifact/0fea041b-1676-4675-94ab-fc326d44bdb3>
- **El grid**: el lienzo «Posts de Instagram NOMAD» (claude.ai/code/artifacts), los nueve posts.
- **Las reglas y los números**: `AGENTS.md`. Léelo antes de tocar nada.

```bash
npm install                       # ffmpeg, once (11 s)
bash piezas/construir-todo.sh     # prepara salida/, escribe todas las piezas y el taller
```
